Overview

hspass is a zero knowledge command line security utility written in Rust. It operates entirely on your local machine with zero external cloud dependencies or remote server tracking.

Key Components

  • Zero Knowledge Cryptography using Argon2id key derivation and AES 256 GCM encryption.
  • FIDO2 and CTAP2 Passkey software emulation using ECDSA secp256r1 keypairs.
  • Continuous live TOTP authenticator with active terminal progress counters.
  • Offline blockchain state anchoring computing SHA3 256 Merkle tree roots.

Quickstart

Build the binary from source using Rust cargo and initialize a new vault:

git clone https://github.com/Hacski/hspass.git
cd hspass
cargo build --release
./target/release/hspass init

Command Reference

1. Password Management

# Generate password
hspass generate github.com --username alice --length 24

# Retrieve stored entry
hspass get github.com

# List all vault services
hspass list

2. Live TOTP Authenticator

# Save secret URI and run live continuous ticker
hspass otp github.com --add-secret "otpauth://totp/GitHub:alice?secret=JBSWY3DPEHPK3PXP"

# Run ticker continuously
hspass otp github.com

3. FIDO2 Passkeys

# Register passkey
hspass passkey register github.com --username alice

# Sign challenge
hspass passkey sign github.com --username alice 416c6963654368616c6c656e6765

4. Security Audit and Blockchain Backup

# Run health scan
hspass audit

# Export signed payload and QR code
hspass blockchain export --qr
